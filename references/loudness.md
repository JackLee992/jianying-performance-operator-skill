# 响度统一：减少等待时保留声音语义

本地静态研究中，复合片段就绪检查会等待内部视频/音频算法，其中包括响度算法。27 份新增响度结果的时间戳落在近期视频缓存完成后 0.18–1.97 秒；这是相关性，不是按任务 ID 对齐后的运行时长。纯音频测量两份约 628 秒原素材各约 2 秒，只说明算术/解码不需要分钟级视频预合成，不说明剪映只要改一个开关就能达到相同速度。

先判断必须解决哪种声音问题：

- **逐片段匹配**：不同讲话者、素材或镜头间的响度需要匹配。成片级全局处理不能代替。若使用源音频一次处理，剪裁、混音、效果、音量和变速仍可能改变最终结果。
- **成片交付目标**：画面锁定后统一最终节目响度，可减少反复改画面触发的准备；但全局处理保留/改变片段相对动态的方式与逐片段匹配不同，须用户接受并听检。
- **保留当前效果**：已经有正确缓存时优先复用。不要在正在排队的工程上反复开/关响度以“试试”，这可能重复触发依赖；本地一次实测关闭勾选未取消已启动的准备。需要停止时使用当前原生任务行的取消控件，并观察实际目标与同组任务变化；不要根据弹窗静止反复重启。该场景只有单项取消及稍后重试通过，取消全部/立即重试未验收。

## 原生批量启用：只选有资格的片段，直接操作 Audio 控件

先完成素材重链、“复制至草稿”、保存复开与画面/效果设置，再批量配置响度，最后集中准备；不要在正在生成时反复迁移来源或切换开关。只选择本次需要处理、确实有音频输入的片段/复合，查看右侧 **Audio / 音频** 面板，在当前可见的响度统一勾选框上直接启用。混合勾选状态不等于全开，操作后逐个抽查启用状态，并按原生任务/输出判断完成；仅勾选 ON 不等于响度计算已经完成。

本机分别选择 2 个和 6 个符合条件的复合时，直接 Audio 勾选可用；6 个混合状态片段可批量设为 ON，既有音量 +5.9 dB、淡入淡出 0 保持原值。这是该选择和设置的原生操作验证，不是建议把其他工程音量改成 +5.9 dB，也不保证所有片段类型/效果组合可用。先记录各片段原有音量、淡入淡出、速度、静音和通道，只改响度目标；不要为了批量操作把它们统一覆盖，也不要无差别同时处理内外复合导致重复归一化。

混入图片，或选到音频已分离、当前视频没有可处理音频的片段，相关控件可能不显示。移除不符合条件的选择、分批处理，已有独立音频则选择真正承担声音的片段；不为露出控件去重新分离或重建复合。测试中的复合“粘贴属性”对话框**没有响度选项**，因此不推荐“只粘贴响度”。静态枚举中有字段不证明原生菜单存在；只有当前 UI 明确提供该项且作用范围验证后，才使用对应入口。

如果用户决定把处理移到源音频或成片后，另存工程/文件并保留原声音；核对采样率、通道、时长、声画同步、真峰值、混音和听感。FFmpeg `loudnorm` 官方文档：[loudnorm](https://ffmpeg.org/ffmpeg-filters.html#loudnorm)。需要执行时查当前版本参数，针对用户目标制定命令，不能将泛用单行命令当作等效替换。

当前没有已验证安全的“所有响度请求改为纯音频输入”补丁。研究这种优化必须保持复合的有效范围、剪裁、变速、混音、效果、通道、缓存身份、取消与所有权，不能偷偷用原始源文件替代渲染后的复合音轨，也不能伪造完成状态。


## 原生分离音频：准备快，但本轮等价对照失败

这是用户可见的编辑流程实验，不是透明的原生纯音频输入补丁。一个独立测试工程从 0 个派生缓存文件起步：首个复合的原生分离动作不足 1 秒；开启分离音频片段的响度后，`audio.m4a` 在 4.628 秒最终化，17 字节响度结果在 5.252 秒出现，原生 UI 显示 -23 LUFS 完成，期间没有生成 video/alpha 输出。该样本证明音频准备可以不等待该视觉缓存，不证明内容等价或最终视频导出更快，不能称为“26 倍完整导出提速”。

在响度都关闭的原流程/分离流程上，原生导出两份完整约 20 分 55 秒 WAV：均为 PCM 16-bit、44.1 kHz、2 声道，报告时长 1255.224308 秒；统一解码为 48 kHz 后均为 60,250,767 帧。**严格 PCM 对照失败**：相对 RMS 误差 0.0106621，最大绝对样本误差 0.0337854，诊断拟合增益 0.999499；两者的通道布局字段均为空，亦未建立布局等价。相同时长、帧数、声道数与接近 1 的增益不能消除已测波形差异。中间编码可能有关，但没有证据确定原因，不用增益或时间对齐“修正通过”。

原始 44.1 kHz PCM 窗口复核进一步定位了差异：两输出均为 55,355,392 帧，全部差异位于被分离的首 627.566667 秒，最后差异在 627.563764 秒；未改动的后半段 55,359,404 个标量样本逐样本一致。首段相对 RMS 误差 0.01568135，最大差 1122 个 PCM16 LSB（约 0.0342407 满量程），超过 1 LSB 舍入。全程误差 0.01066240 与 48 kHz 检查吻合，说明本轮差异不是比较重采样造成；中间 AAC 编码是否为原因仍未确定。差异被定位不等于可接受，严格等价门槛仍未通过。

因此不自动分离音频，也不把它作为默认生产建议。条件实验使用另存工程：先确认原生菜单可用、生成的材料类型、视频原音是否被静音以免双重叠加；再以响度关闭的原生无损输出核对通道布局、样本、有效区间、混音、增益、淡入淡出、变速和效果。波形不等价时保留原音流程，记录差异，停止透明替换结论；只有针对该用途的声音语义被验证后才比较响度/完整导出总成本。

本轮归一化开启的原生输出对照尚未完成，效果/混音覆盖与人工听检也未完成。UI 显示 -23 完成不替代这些验收。外部音频测量速度、原生音频准备速度、编辑语义等价与完整导出速度应各自报告。

协议与只读检查/PCM 比较工具见 [audioonly experiment](https://github.com/JackLee992/jianying-macos-performance-patches/tree/main/experiments/audioonly)。原始输入、原声音、原工程和有效缓存保留；不为测试清理原工程缓存或伪造算法完成。
